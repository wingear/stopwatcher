# Stopwatcher

🕒 A smart stopwatch for freelancers and everyone who wants to take control of their time.

---

## English Description

Stopwatcher is an intelligent stopwatch application designed for freelancers and anyone seeking better time management. It offers intuitive controls and powerful features to help you stay productive and mindful of your work.

### Features

- ⏯️ Start/Pause with a single mouse click, Reset with a double click.
- 🕹️ Adjust hours, minutes, and seconds manually using the mouse wheel while paused.
- 👤 Automatic pause when you’re away from your PC (detects mouse and keyboard activity).
- 📊 Visual progress bar shows how long before auto-pause activates.
- 🔔 Taskbar blinking to remind you to resume after inactivity.
- 📌 "Always on top" window mode.
- 🌫️ Adjustable transparency for a non-distracting experience.
- 🏷️ Custom labels for timers (e.g., “Task 392”, “Work”, “Break”).
- 💾 Automatic saving of elapsed time every 5 minutes to a file located in the same directory as the stopwatch .exe file.
  (The file is deleted automatically when the application is closed via the “X” button. In all other cases, it is preserved to allow time recovery).
  
Most features are configurable or can be turned off in the settings.

## Описание на русском

Stopwatcher — это умный секундомер для фрилансеров и всех, кто хочет взять своё время под контроль. Минималистичное управление и продвинутые функции помогут вам работать осознанно и эффективно.

### Основной функционал

- ⏯️ Запуск и пауза — одним кликом мыши, сброс — двойным кликом.
- 🕹️ Ручная корректировка часов, минут и секунд прокруткой колеса мыши во время паузы.
- 👤 Автоматическая пауза при отсутствии активности (реагирует на действия мышью и нажатия на клавиатуре).
- 📊 Прогресс-бар показывает, сколько времени осталось до автопаузы.
- 🔔 Мигает в панели задач при паузе, чтобы вы не забыли продолжить работу.
- 📌 Режим "поверх всех окон".
- 🌫️ Регулируемая прозрачность.
- 🏷️ Возможность задавать название секундомеру (например, “Задача 392”, “Работа”, “Отдых”).
- 💾 Автоматическое сохранение прошедшего времени каждые 5 минут в файл, который создается в том же каталоге, где и находится .exe файл секундомера (Удаляется автоматически при закрытии через крестик. В остальных случаях сохраняется, чтобы была возможность восстановить время).

Большинство функций можно настроить или отключить по вашему желанию.
